# Shared Dependency Planner

Shared Dependency Planner helps teams organize work, connect prerequisites, and see what is ready, blocked, or complete.

## Open the planner

Visit [shared-dependency-planner.web.app](https://shared-dependency-planner.web.app) and sign in with your Google account.

## What you can do

- Create team spaces and keep each team's planners together.
- Add tasks with descriptions and time estimates.
- Connect tasks to show dependency relationships and prevent circular dependencies.
- See task priorities, blockers, and the remaining critical path.
- Arrange task cards on a shared visual board using drag and drop.
- Use the mobile-friendly list view to update tasks and prerequisites.
- Export a planner as PNG, SVG, Mermaid Markdown, or JSON.
- Create a view-only link for people outside your team.

## Get started

1. Sign in with Google.
2. Create a team or open a team you have joined.
3. Create a planner or select an existing one.
4. Add tasks and connect their prerequisites.
5. Drag task cards to arrange the shared board, or choose **Auto-arrange**.

Changes are saved automatically and appear for other team members using the same planner.

## Access and sharing

- Team members can create and edit planners in their team space.
- Team owners and administrators can invite members and manage view-only sharing links.
- Anyone opening an external sharing link can view the planner but cannot edit it.
- Sharing links are unlisted and can be revoked by an owner or administrator.

## Mobile use

Phones open planners in the list view by default. Use it to add, edit, complete, or delete tasks and change prerequisites. The graph remains available for viewing, panning, and zooming.

## Exporting to Confluence

Open **Export** from a planner and choose PNG or SVG, then upload the file to Confluence. Mermaid Markdown is available when editable diagram text is preferred.

## Need help?

Open **Help** in the application for concise instructions covering tasks, dependencies, sharing, exporting, and saving.
