# Dependency-based Project Planner v0.1.1

Download the v0.1.1 ZIP from the repository, unzip it, and open the HTML file in a modern browser. The app works offline and does not require installation.

The app supports task descriptions, required time estimates, drag connections for dependencies, priority numbers, and a remaining critical path estimate.

Version 0.1.1 adds task deletion. Delete a task from its node editor; its dependency links are removed with it.

Tasks are stored in the browser where the file is opened. Use **Export data** and **Import data** to move tasks from the localhost preview or an older downloaded file.
